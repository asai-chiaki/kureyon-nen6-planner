# くれよん 年6回プランナー

地域みっちゃく生活情報誌「くれよん」の広告を **年6回** で組むときの、掲載号・版・料金のシミュレーションと、お客様に渡すA4一枚の提案書を作るWebページです。

ブラウザだけで使えます（Claude やアカウントは不要）。

## 使う

公開ページを開くだけです → **https://asai-chiaki.github.io/kureyon-nen6-planner/**

1. お客様名・業種・掲載版と回数・広告の種類とサイズ・開始の号を選ぶ
2. 「業種のおすすめで組む」を押す → 6回の号・版・理由のたたき台が入る（表はそのまま書き直せます）
3. 「PDFをダウンロード」→ お客様用のA4一枚

入力内容はそのパソコンのブラウザにだけ保存されます。ほかの人には見えません。

### 「おすすめで組む」のしくみ

- 業種ごとの ◎ピーク号・○効く号（`data.js` の `INDUSTRY`）に点数をつける
- 周年の号、近くの同業店がオープンする前の号・当月の号は点数を上乗せ
- 締切を過ぎた号は選ばない
- 掲載の間が3か月を超えない組み合わせの中から、点数がいちばん高いものを選ぶ
- 回数の多い版（メイン版）を、点数の高い号に割り当てる

## 直す（料金・部数・業種のピーク月など）

数字や文言は **`data.js` だけ** にまとめてあります。GitHub の画面から直せます。

1. このページの一覧から `data.js` を開く
2. 右上の鉛筆マーク（Edit this file）を押す
3. 数字を書き換える（`,` や `"` を消さないように注意）
4. 右上の「Commit changes...」→ もう一度「Commit changes」
5. 1〜2分で公開ページに反映されます

| 直したいもの | `data.js` の場所 |
| --- | --- |
| 料金表の版（A4の注記） | `PRICE_SOURCE` |
| 版の名前・色・部数・配布日 | `ED` |
| 1回あたりの掲載料 | `P`（並びは 年1回,2回,3回,4回,5回,6〜8回,9〜11回,12回） |
| 制作費 | `PROD` |
| 月ごとの出来事 | `MONTH_THEME` |
| 業種と ◎ピーク号・○効く号 | `INDUSTRY` |
| A4の「年6回をおすすめする理由」 | `WHY` / `WHY_SOURCE` |

編集するには、このリポジトリの編集権限（Collaborator）が必要です。権限がない人は、編集すると自動で「変更の提案（Pull Request）」になり、管理者が確認してから反映されます。

## ファイル

- `index.html` … ページ本体（画面と計算）
- `data.js` … 料金・版・業種などのデータ

## 「サイトを読んでプランを作る（AI）」（中継サーバー）

`worker/` フォルダは、お店のサイトや担当者のメモを読んで、キャッチ・お店の魅力3点・号ごとの理由とテーマを書く中継サーバーです。AIは12号それぞれに「このお店にとっての価値」を付け、最終的な号はページ側で「締切前・ピーク号を入れる・間を3か月以内・版の回数どおり」のルールで決めます。Cloudflare Workers と Workers AI（Google Gemma 4）の無料枠で動き、クレジットカードの登録はいりません。

- 無料で使えるのは1日10,000ニューロン（1回およそ100ニューロン、1日100回程度）。使い切ると翌朝9時（日本時間）に戻ります。上限を超えても料金はかからず、その日は使えなくなるだけです
- 合言葉（`PASSCODE`）を知っている人だけが使えます。合言葉は最初の1回だけ聞かれ、そのブラウザに保存されます
- 呼び出せるのはこの公開ページからだけです（`wrangler.toml` の `ALLOWED_ORIGINS`）
- 中継サーバーのURLは `data.js` の `MIRYOKU_API` に書きます（空ならボタンは出ません）
